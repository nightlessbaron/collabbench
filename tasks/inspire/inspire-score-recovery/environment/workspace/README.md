# Cadence Rights Exchange — recovery workspace

The source files of the catalogue were lost when the publisher closed; what
survives is the retired engraver's SVG export. The pieces in this workspace are:

- `corpus/reference/` — the surviving editions, one bundle per directory.
- `corpus/submissions/` — submissions for the current licensing window.
- `corpus/manifests/` — JSON manifests for the two datastores.
- `corpus/feed/` — the paginated partner submission feed.
- `kit/` — two worked example bundles, each with `expected.json`.
- `partner_toolkit_src/` — working sources of the partner toolkit.
- `data_bundle_src.json` — working source of the published title bundle.
- `docs/` — engraver file format, output contract, publishing policy.

The engraver export format is described in `docs/engraver-format.md`; the
deliverable formats and commands are in `docs/output-schema.md`.
