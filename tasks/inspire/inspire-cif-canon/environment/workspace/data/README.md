# Helix Structural Genomics Center — Release 7 archive

The HDX-3 detector vendor has dissolved and the last controller workstation is
being powered down. Release 7 is the replacement offline data platform, built
air-gapped from what the center can still read.

`/workspace/data/structures` holds a few deposits exported from the old platform
in CIF form. They are small, ordinary structures of the kind the beamlines
produce day to day. The full archive is far larger and was canonicalised at
deposit time by a pinned library; the porous-materials and drug-discovery groups
depend on Release 7 reproducing that canonicalisation for every valid CIF
deposit, not only the samples copied here.

`/workspace/data/provenance` records the migration history. Nothing in this
directory computes anything; it is background material recovered from the old
system.
